This folder contains the static data used by the application.

Files:
- `btw2021/first_votes.json`
  - Constituency-aware first-vote records used to determine district winners for the active scenario.
- `btw2021/second_votes.json`
  - Constituency-aware second-vote records used to calculate party results and seats for the active scenario. The demographic presentation aggregates its age, gender, and voting-method distribution from the same records.
- `partyData.json`
  - Party names, abbreviations, colours, and parliamentary positions.
- `germany_states_map.geo.json`
  - GeoJSON geometry for the German federal states.

`btw2021/first_votes.json` and `btw2021/second_votes.json` are generated by the notebook workflow under `scripts/notebooks/btw2021/`. Their shared record model and preparation methodology are documented in `scripts/README.md`.

The `btw2025/` folder holds prepared BTW 2025 data that is not yet wired into the application. `src/data/loaders.ts` continues to load the BTW 2021 files until the 2025 scenario is ready to be used.
