This folder contains the static data used by the application and the prepared vote JSON used to generate its runtime assets.

Election-specific source files:
- `btw2021/first_votes.json` and `btw2025/first_votes.json`
  - Constituency-aware first-vote `VoteEntry` records generated by the notebook workflows.
- `btw2021/second_votes.json` and `btw2025/second_votes.json`
  - Constituency-aware second-vote `VoteEntry` records generated by the notebook workflows.

The JSON files remain the human-readable, validation-friendly output of the Python data preparation. The web application does not load them directly anymore.

Generated runtime files:
- `btw2021/first_votes.bin`, `btw2021/second_votes.bin` and `btw2021/vote_data.json`
- `btw2025/first_votes.bin`, `btw2025/second_votes.bin` and `btw2025/vote_data.json`

These files are generated from the source JSON by `scripts/export_vote_binary.py`. The binary files store the large repeated vote dimensions as compact integer columns and keep vote values as 64-bit floats. `vote_data.json` contains the versioned dictionaries and constituency-to-state metadata needed to decode the files.

The generated runtime files are intentionally ignored by Git. `npm run dev` and `npm run build` generate them automatically. Production builds remove the four large source vote JSON files from `dist/`, so GitHub Pages only serves the compact runtime representation.

Shared and supporting files:
- `partyData.json`
  - Party names, abbreviations, colours, and parliamentary positions used across the supported elections.
- `germany_states_map.geo.json`
  - GeoJSON geometry for the German federal states.
- `state_seat_contingents_2021.json` and `state_seat_contingents_2025.json`
  - Election-year-specific distributions of the 598 initial seats among the federal states for simulations with the pre-2023 electoral-law model.

The vote JSON files are generated by the notebook workflows under `scripts/notebooks/btw2021/` and `scripts/notebooks/btw2025/`. Their shared record model and preparation methodology are documented in `scripts/README.md`. The binary runtime format is documented in `docs/BINARY_VOTE_DATA.md`.

`src/data/loaders.ts` selects the matching binary vote files and state-seat-contingent fixture for the election chosen in the application.
