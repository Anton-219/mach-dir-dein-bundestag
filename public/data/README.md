This folder contains the static data used by the application.

Files:
- `first_votes.json`
  - Constituency-aware first-vote records used to determine district winners for the active scenario.
- `second_votes.json`
  - Constituency-aware second-vote records used to calculate party results and seats for the active scenario.
- `stat_votes.json`
  - Demographic reference vote records used by the demographic presentation.
- `partyData.json`
  - Party names, abbreviations, colours, and parliamentary positions.
- `germany_states_map.geo.json`
  - GeoJSON geometry for the German federal states.

`first_votes.json` and `second_votes.json` are generated by the notebook workflow under `scripts/notebooks/btw2021/`. Their shared record model and preparation methodology are documented in `scripts/README.md`.
