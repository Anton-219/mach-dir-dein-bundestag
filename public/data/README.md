This folder contains the data used in the project.

Files:
- `election_results_direktmandate.json`
  - Describes the number of winners of the Wahlkreise. "Direktmandatsgewinner"
- `first_votes.json`
  - Describes the vote statistics for the first votes. "Erststimmenstatistiken"
- `germany_states_map.geo.json`
  - GEO Json Data of German with its states.
- `partyData.json`
  - Data for the parties.
- `second_votes.json`
  - Describes the vote statistics for the second votes. "Zweitstimmenstatistiken"
- `stat_votes.json`
  - Describes the general vote statistics for the full country.
